MEPHITIDEUS INTERACTIVE PRESS KIT
=================================

ABOUT THE STUDIO
Mephitideus Interactive is an independent game studio focused on approachable
action games and browser-first experiences.

PUBLISHED GAME
Skunked: Way of the Spray is a 2D beat 'em up platformer starring a ninja skunk.
A free browser demo is available at https://skunked.io/. The full campaign is
available on Steam and Google Play.

GAME IN DEVELOPMENT
Chip Savage Golf: Underground Tour is an arcade-golf action game in early
development and still a long way from release. The current browser build is an
early preview. Features and presentation may change. The studio is beginning to
build awareness and has not announced a release date.
